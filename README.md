# Entrepreneurship-Hub
E-HUB (Entrepreneurship Hub) is a strategic project of the Entrepreneurship Department aimed at building a central digital system to manage, store, and utilize data for all academic entrepreneurship activities at FPT University.


Phase 1: Rubric-based Grading Backend        ✅ bạn đã làm
Phase 1.5: Kiểm thử + khóa nghiệp vụ          ← nên làm ngay
Phase 2: Lecturer Grading UI                  ← bước tiếp theo chính
Phase 3: Admin Evaluation Management
Phase 4: Analytics Dashboard
Phase 5: AI Evaluation Assistant
Phase 6: Pilot + Production Hardening
